Friday 27 November 2026: 36 dated stories, 6 illustrated heroes, a pinned
world map — the whole day's world news on one front page. Pure Python
standard library: the picture is painted onto a pixel buffer, the text is
drawn with a small bitmap font defined in the program, and the PNG bytes
are encoded by hand. No third-party library, no network, and the same
bytes come out every run.

## Run it

```sh
python3 main.py
```

Writes `entry.png` (1024x1024, under 1 MiB) to `/output` — or to
`$MAKEFUN_OUTPUT_DIR` when that is set.
